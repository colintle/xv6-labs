1. Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?

Function arguments are passed in registers a0 through a7. In main's call to printf, a0 contains the address of the format string, a1 contains f(8)+1, and a2 contains 13. So 13 is held in register a2.

2. Where is the call to function f in the assembly code for main? Where is the call to g? (Hint: the compiler may inline functions.)
There is no actual call to f or g in main. The compiler inlined both functions. Since g(x) returns x+3 and f(x) returns g(x), the compiler directly computes f(8)+1 as 12.

4. What value is in the register ra just after the jalr to printf in main?
The call to printf is at address 0x30.The ra register gets the address of the next instruction: ra = 0x30 + 4 = 0x34. So just after the jal to printf: ra = 0x34

6. In the following code, what is going to be printed after 'y='? (note: the answer is not a specific value.) Why does this happen?

	printf("x=%d y=%d", 3);

After y=, it prints an unpredictable garbage value.
Reason: the format string asks for two integers, but only one integer argument was passed. printf still tries to read the next argument location, so it prints whatever value happens to be there.
